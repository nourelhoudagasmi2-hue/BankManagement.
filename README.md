# BankManagement — Java Application

A banking management system developed in Java using Object-Oriented Programming (OOP) principles.

## Project Overview

BankManagement is a Java application designed to manage bank clients and their accounts. It allows users to perform basic banking operations while applying important OOP concepts.

## Features

- Create and manage clients.
- Create bank accounts.
- Manage current accounts.
- Manage savings accounts.
- Deposit money.
- Withdraw money.
- Check account balances.
- Handle banking exceptions.
- Save and load client information using text files.

## Main OOP Concepts

This project demonstrates several fundamental Object-Oriented Programming concepts:

- **Encapsulation:** Protecting data using private attributes and public methods.
- **Inheritance:** Creating specialized account classes from a common account class.
- **Polymorphism:** Using common interfaces and methods with different implementations.
- **Abstraction:** Organizing essential behaviors and hiding implementation details.
- **Exception Handling:** Managing invalid operations and unexpected errors.
